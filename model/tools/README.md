**规划模型**:

- 安全装备检测（安全带、绝缘手套等）

## 应用场景

1. **工器具盘点**: 施工前后清点工具数量
2. **安全装备检查**: 检测工人是否佩戴安全带、绝缘手套
3. **装备入库**: 新装备拍照自动识别并登记

## 与 PPE 模型的区别

- **PPE 模型** (yolo11n-ppe): 视频实时检测，关注安全帽、反光衣等穿戴类
- **工具模型** (预留): 照片处理，关注手持工具、大型装备

## 技术约束

- 工具种类繁多，需大量标注数据
- 可考虑先部署 COCO 通用检测，再逐步替换为专用模型
