## 应用场景

1. **安全装备检查**: 检测工人是否佩戴安全带、绝缘手套
2. **装备入库**: 新装备拍照自动识别并登记

## 与 PPE 模型的区别

- **PPE 模型** (yolo11n-ppe): 视频实时检测，关注安全帽、反光衣等穿戴类
- **安全装备模型** (预留): 照片处理，关注安全带、绝缘手套等作业防护类

## 技术约束

- 装备种类繁多，需大量标注数据
- 可考虑先部署 COCO 通用检测，再逐步替换为专用模型
